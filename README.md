## FAQ

### What is XCutors?

XCutors is a collection of popular Roblox executors bundled with a universal loader, designed to run Lua scripts for game customization on Windows.

### Is this safe to use?

These tools are used for educational and customization purposes. We recommend using them responsibly and within Roblox's terms of service.

### Do I need multiple executor accounts?

No, the xcutorsLoader manages multiple executors from a single interface, but each executor may require its own license or setup.

### How often is the package updated?

We aim to update the package whenever major changes occur for any included executor, ensuring compatibility with the latest Roblox updates.

### Can I contribute my own executor?

Currently, the package focuses on the listed executors. For suggestions, please open an issue in the repository.

### Does it work on macOS or Linux?

XCutors is designed exclusively for Windows. Some executors may have alternative versions for other OS, but they are not included here.

### What scripts can I run?

You can run any compatible Lua script, including those from public script hubs or custom scripts you create.

### Is there a key system?

Some included executors may require their own valid license keys, which must be obtained separately from their official sources.
